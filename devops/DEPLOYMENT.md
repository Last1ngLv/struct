# DEPLOYMENT.md - Despliegue

## Proceso de Despliegue

### 1. Preparación
- Verificar que todo el código compila
- Asegurar que dependencias están incluidas
- Verificar recursos (modelos, sonidos) importados

### 2. Compilación
- Abrir mapa en World Editor
- Guardar y cerrar triggers
- Compilar con JASSHelper

### 3. Exportación
- Exportar mapa como .w3x
- Verificar tamaño del archivo

### 4. Testing Final
- Test en cliente Warcraft III
- Verificar semua feature works

## Entorno
- World Editor (parte de Warcraft III)
- JASSHelper para compilación

## Distribución
- Plataformas: Battle.net, Hive Workshop
- Formato: .w3x (archivo de mapa)
