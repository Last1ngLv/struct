# DOCKER_GUIDE.md - Guía Docker

## Estado
**No aplicable**: Este proyecto no usa Docker.

## Razón
Warcraft III map development:
- Requiere World Editor (solo Windows)
- No es aplicación containerizable
- Testing requiere cliente Warcraft III

## Alternativas
- Desarrollo directo en Windows
- Almacenamiento en Git para compartir

## Notas
- No se proporciona Dockerfile
- No se proporciona docker-compose.yml
- Proyectopuramente de desarrollo de mapas Warcraft III
