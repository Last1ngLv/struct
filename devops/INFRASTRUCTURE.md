# INFRASTRUCTURE.md - Infraestructura

## Estructura de Archivos
```
struct/
├── .git/                   # Git repository
├── .github/                # GitHub config
├── .vscode/                # VS Code config
├── libraries/              # Librerías vJASS core
├── MyMissiles/             # Sistemas personalizados
├── MissileExamples/        # Ejemplos por héroe
├── agents/                 # Documentación de agentes
├── docs/                   # Documentación técnica
├── knowledge/              # Base de conocimiento
├── quality/                # Documentación de calidad
└── devops/                 # Documentación de despliegue
```

## Entorno de Desarrollo
- Editor: VS Code con extensión TESH (JASS syntax)
- Compilador: JASSHelper
- Mapa base: Warcraft III World Editor
- Version control: Git

## Recursos
- Repositorio Git local
- Configuración de VS Code en .vscode/
