# VJASS Structs para Warcraft III 1.27b

Este repositorio contiene **estructuras (`structs`) y sistemas en VJASS** para Warcraft III versión 1.27b.  
Está pensado para desarrolladores que quieren **facilitar la creación de mapas personalizados** y **automatizar tareas comunes** usando VJASS.

## 📦 Contenido

- Archivos `.j` y `.vj` con definiciones de structs.
- Funciones y sistemas reutilizables para mapas.
- Ejemplos de cómo implementar y usar las estructuras en tus mapas.

## ⚙️ Requisitos

- Warcraft III versión 1.27b.
- Editor de mapas compatible con JASS/VJASS (como **World Editor** o **WE 1.32+** con JassHelper).
