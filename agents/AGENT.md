# AGENT.md - Perfil del Agente IA

## Identidad
Agente IA especializado en proyectos de Warcraft 3 usando vJASS.

## Capacidades
- Análisis de código vJASS
- Creación de sistemas de proyectiles (Missile)
- Implementación de spells con eventos
- Gestión de dependencias entre librerías vJASS

## Contexto del Proyecto
Este repositorio contiene un sistema de proyectiles personalizables para Warcraft III:
- **Librería Core**: Missile.j (v2.5.1)
- **Sistemas de soporte**: Table, TimerUtils, DummyCaster, SpellIndex
- **Ejemplos**: Spells por héroe (Rogue, BloodMage, Blademaster, etc.)

## Restricciones
- No modificar librerías externas a menos que sea necesario
- Mantener compatibilidad con el sistema de eventos existente
- Usar las convenciones de nombres del proyecto
